# 総括レポート：守備側コンパクトネスの理論逸脱分析（コンペテーマ選定用）

このドキュメントは、hs-pinnプロジェクト（守備側コンパクトネスへの理論逸脱分析）のこれまでの成果を、手法・結果・解釈・結論・課題・対処法の順にまとめ、今後参加予定のコンペ（フルトラッキングデータ64試合分が利用可能）でこのテーマを継続すべきかどうかの判断材料とするものである。

---

## 1. 手法の概要

**研究設問**：カウンター攻撃において、守備側が「コンパクトネス」という戦術セオリー（間延びした守備＝カウンターが刺さりやすい、という古典的定石）からどれだけ逸脱しているかは、カウンターの成功/失敗と関係するか。単なる一般的な予測誤差ではなく、理論からの逸脱そのものを測定できるか。

**データ**：idsse-data（Bundesliga、7試合、kloppy経由）。カウンター攻撃候補イベントを抽出（n=502）。

**中核となる測定手法（超過逸脱度）**：
- modelA（データ駆動ghost、λ=0）：実際の守備行動を模倣する、理論なしのモデル
- modelB（理論駆動ghost、λ=0.5）：同一アーキテクチャに、コンパクトネスへの矯正を損失関数（L_theory）として加えたモデル
- 超過逸脱度 = d(実観測, modelB) − d(実観測, modelA)：一般的な予測誤差を差し引くことで、理論からの逸脱という成分を分離する設計
- 守備側のみを予測対象とし、攻撃側は実際の観測軌道をそのまま条件として入力する（非対称設計）

**検証プロセス（3段階ゲート）**：
1. 段階1：観測データへの直接相関（モデル学習なし、交絡変数を制御）
2. 段階2：損失関数としての機能スクリーニング（勾配の健全性・λ応答・退化解の3基準）
3. 段階3：modelA/B構築とLeave-One-Match-Out交差検証（7-fold）による超過逸脱度の算出

---

## 2. 主結果

| 検証 | 結果 |
|---|---|
| 段階1（生の相関） | 奪取位置を制御してもコンパクトネスと成功率の相関は消えず、むしろ強化 |
| 段階2（損失関数スクリーニング） | コンパクトネスは3基準を通過。ピッチコントロール系（L_space）は不安定で放棄 |
| 段階3・主結果（λ=0.5、5シードアンサンブル） | β=+0.293, p=0.0368（n=502、奪取位置で交絡制御） |
| λの応答パターン（0.1〜16の全域） | 0.1・0.25で弱く非有意、λ=0.5でピーク、λ=8で崩壊——理論通りの山型を確認 |
| modelA単独との対照比較 | modelA単独の誤差は交絡制御で消える（p=0.319）が、超過逸脱度は残る＝一般的な予測困難性では説明できない |
| チーム別集計（参考値） | 超過逸脱度が最も高いチームは被カウンター成功率も最高、最も低いチームはゼロ。r=+0.530, p=0.1147（n=10チーム、疑似反復注意） |
| 連続量ΔxTへの切り替え | naive p=0.037→0.018と改善したが、クラスタロバスト補正では有意水準に届かず |

---

## 3. 解釈

- 回帰係数の符号・大きさ（+0.293）は、通常の検定・クラスタロバスト検定・連続量への置き換えなど、あらゆる検証を通じて一度も反転・消失しなかった
- λに対する応答は、弱すぎても強すぎても効果が薄れるという理論的に予測される山型を示しており、単純な人工物とは考えにくい
- 「単に予測しにくい非定型な守備だったから失点した」という代替説明は、modelA単独の対照検定で否定された

---

## 4. 結論

**守備側コンパクトネスへの理論逸脱がカウンター成功と関係するという、方向性が一貫した示唆的な証拠が、複数の独立した検証を通じて得られた。** しかし、**7試合という限られたデータでは、この効果を統計的に「確定した」と主張することはできない**（5節参照）。これは効果が存在しないことの証明ではなく、判定するための統計的検出力が原理的に不足している、という状態である。

副次的な成果として、**modelA/modelB差分（超過逸脱度）という測定手法には構造的なバイアスが内在することを発見し、合成データによる定量化・キャリブレーション手法を確立した**。これは特定の理論（コンパクトネス）に限定されない、手法論としての貢献である。

## 5. 課題

### 課題1：疑似反復（データの独立性）
502件のイベントは実質7試合・10チームに由来し、同一試合・同一チームの観測が繰り返し登場する。これを無視した通常の回帰は標準誤差を過小評価し、p値を過大に楽観的にする。

- クラスタロバスト標準誤差で再検定：p=0.0368（通常）→p=0.1388（試合単位）／p=0.0670（チーム単位）
- ただしクラスタ数（7〜10）は、クラスタロバストSEが信頼できるとされる目安（20〜50）を大きく下回り、この補正値自体も精密ではない

### 課題2：構造的な下駄（測定手法自体のバイアス）
modelBは理論への矯正で単一の「理想形」に強く引き寄せられるため、真の戦術逸脱がゼロでも構造的にmodelAより観測から離れやすい。

- 合成データ（「理論が完全に正しい」と仮定した疑似観測）でキャリブレーションしたところ、真の逸脱ゼロのはずの状況でも超過逸脱度+0.035が検出された
- 実データの単一シード超過逸脱度(+0.055)のうち約64%がこの構造的な下駄で説明できる
- 絶対水準の解釈には要注意。ただし下駄はほぼ一定オフセットのため、回帰係数への影響は理論上小さいと考えられる

### 課題3：データ量そのものの上限
7試合というデータ規模は、疑似反復・統計的検出力のどちらの問題においても、根本的な制約になっている。

## 6. その対処法（試したこと・今後の道）

**既に実施したこと**：
- クラスタロバスト標準誤差による疑似反復の定量化（課題1）
- 合成データによる構造的下駄のキャリブレーション（課題2）
- 連続量アウトカム（ΔxT）への切り替えによる検出力向上の試み（部分的に改善、決定打には至らず）
- modelA単独との対照比較による代替説明の排除

**費用対効果が低いと判断し見送ったこと**：
- 別の理論指標（最終ラインの統率等）へのスペア展開：測定手法自体の限界（課題1・2）は指標に依存しないため、根本解決にならない
- Wild cluster bootstrap等のより高度な少数クラスタ対応統計手法：これも「7試合しかない」という壁自体は動かせない

**未実施・今後の候補**：
- イベントごとの下駄補正（既存の学習済みモデルを流用し、モンテカルロサンプリングで各イベント固有の構造バイアスを推定）：追加学習不要で実施可能
- modelBを点予測ではなく確率分布で出力させ、尤度ベースで評価する、より根本的な再設計（コスト大）

**最も効果が見込める対処法：データ量の拡大**
今回の課題（疑似反変・検出力不足）の大部分は、根本的にはデータ量（試合数）の制約に起因する。試合数が増えれば：
- クラスタ数が増え、クラスタロバストSE自体の推定精度が向上する（20〜50クラスタという目安に近づく）
- 標準誤差が縮小し、同じ大きさの効果でも有意水準を超えやすくなる（試合数が7→64なら、ラフな見積もりで標準誤差は約1/3に）
- 本格的な混合効果モデルが実装コストに見合うようになる
- 構造的下駄のキャリブレーションもより精密に行える

現在のパイプラインは、データ読み込み層（`counter_events.py`・`trajectories.py`）とそれ以降（モデル・学習・3段階検証・λスイープ・アンサンブル・バイアスキャリブレーション）が、`CounterTrajectory`という共通形式を介して分離された設計になっている。そのため、新しいトラッキングデータ形式（kloppy非対応の可能性が高い）から`CounterTrajectory`を作る変換層さえ実装すれば、それ以降の検証パイプラインはほぼそのまま再利用できる。

## 7. 他テーマとの比較における意見

このテーマを強引に継続する必要はなく、他の候補テーマとの比較の上で判断されるべきだが、参考として現時点の見立てを述べる。

**継続を推す理由**：
- 統計的な弱さの主因（疑似反復・検出力不足）は、根本的にデータ量の問題であり、64試合という約9倍のデータでほぼ正面から解決が見込める。今回何ヶ月もかけて特定した弱点に、ピンポイントで効く増強である
- 検証パイプライン・ドメイン知識（カウンター定義、ハード制約パラメータ、落とし穴の経験）はすでに蓄積されており、新しいテーマからゼロで始めるより着手コストが低い
- 新規実装が必要なのは主にデータ読み込み層のみで、モデル・検証手法一式は再利用できる
- 構造的下駄というこのテーマ固有の発見自体が、汎用性のある方法論的な貢献になっている

**留意すべきリスク**：
- コンペのトラッキングデータの形式・品質が未知数（kloppy非対応と分かっている以上、パーサー実装コストは実際に見てみないと確定しない）
- データ量が増えても、効果の「大きさ」自体（β）が劇的に伸びる可能性は低い（カウンター成否は多要因で決まるため）。得られるのは「確からしさの向上」であって「派手な効果量」ではないと想定しておくべき
- 他の候補テーマの内容を把握していないため、相対比較はできていない

**総合的な見解**：スイッチングコストの低さと、統計的弱点への直接的な処方箋という2点から、他の候補テーマが明確に有望でない限り、このテーマを継続する方向に分がある、というのが客観的な見立てである。ただし、これはあくまで「今回の弱点が解消される見込みが高い」という話であり、「劇的に強い結果が出る」ことを保証するものではない。
