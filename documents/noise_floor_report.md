# ノイズの床の簡易把握

計画書11.9節項目3に対応。「理論的な逸脱が本当にゼロでも、測定方法自体（modelBの学習に伴うランダムな誤差）のせいで最低限出てしまうdist_Bの値」を確認した。

新規の学習は行わず、既存の計算結果を再利用した。

- **ノイズの床**：`data/processed/synthetic_bias_calibration_sigma2.0.pkl`（`synthetic_bias_calibration.py`が既に生成済み。理論的に理想的な守備＝Y_theoryにノイズを加えただけの合成データを「観測」として使い、真の理論逸脱がゼロの状態でmodelB(λ=0.5)を7-fold LOMO-CVで学習・予測した結果。単一seed）
- **実データのdist_B**：`data/processed/stage3_excess_deviation_lam0.5.pkl`（アンサンブル前の単一seed版。ノイズの床と条件（λ=0.5、単一seed、7-fold LOMO-CV）を揃えるため、5シードアンサンブル版ではなくこちらを使用）

## 結果

| | dist_B 平均 | 標準偏差 |
|---|---|---|
| ノイズの床（合成、真の逸脱ゼロ） | 2.60 | 0.14 |
| 実データ | 2.58 | 0.89 |

- 実データの53%は、ノイズの床の平均（2.60）を下回っている
- ノイズの床は非常に狭い分布（標準偏差0.14）である一方、実データは大きく広がっている（標準偏差0.89、範囲0.55〜6.98）
- ランキング上位10%（`lift_precision_at_k_report.md`でLift=1.94倍を確認した50件）のdist_Bは3.78〜6.98の範囲で、**全件がノイズの床の「平均+3標準偏差」（3.01）を上回っている**

## 解釈

「典型的な1事例のdist_B」は、理論違反が本当にゼロでも出るノイズの範囲とほとんど区別できない。個々の事例のdist_Bの値を単体で「理論違反の大きさ」として解釈することはできない。

一方、**分布の上位に絞ると話が変わる**。ランキング上位10%の値は、ノイズの床から明確に外れた範囲にあり、単なる測定ノイズでは説明できない。これは、11節で採用した「個々の値のキャリブレーションは求めず、上位のランキング性能（Lift/Precision@K）だけを評価する」という設計と整合しており、その前提の妥当性を追加で裏付ける結果である。

## 注記（比較の前提）

本チェックは単一seedモデルで統一して比較しており、他の分析（`lift_precision_at_k_report.md`等）で使っている5シードアンサンブル版の絶対値とは異なる（アンサンブルは個々の予測ノイズを平均で打ち消すため、一般に単一seedよりdist_Bが小さくなる）。今回の目的は「ノイズの床と実データの相対的な位置関係」の確認であり、条件を揃えるために単一seed同士で比較した。
