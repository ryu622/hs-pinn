# λ=8でのアンサンブル診断：強い制約は救えなかった

「λ=0.5が最も頑健という結果は、制約が弱すぎて物足りないのでは」という指摘を受け、λ=8（複数シードで最も不安定だった設定、`documents/stage3_multiseed_report.md`）でもアンサンブル（5シード平均）を試し、ノイズを減らせば強い制約でも意味のある結果が出るか診断した。

コード：`scripts/stage3_ensemble.py --lambda_b 8.0`

## 結果

| | λ=0.5アンサンブル（採用） | λ=8アンサンブル（診断） |
|---|---|---|
| 超過逸脱度 std | 0.241 | **0.696**（大きいまま） |
| 交絡制御後 β | +0.293 | +0.098 |
| p | 0.0368 | **0.516（非有意）** |

λ=0.5では5シード平均でstdが0.399→0.241に縮小し明確な効果が出たが、λ=8では平均してもstdが0.696のままで、効果も消えた（p=0.516）。

## 解釈

これは「λ=8のシード間ばらつきは単純な学習ノイズだった」という仮説を**否定する**結果である。もし単純なノイズなら、λ=0.5の時と同様にアンサンブルで大きく改善するはずだった。改善しなかったことは、λ=8では各シードが**質的に異なる局所解**（同程度にコンパクトだが、選手の配置パターンが本質的に異なる複数の「解」）に収束しており、それらを平均すると、どの解の意味も持たない曖昧な予測になってしまう、という説明を支持する。

## 結論

λ=0.5が最も頑健だったのは、単に「探索が不十分で弱い設定しか試していない」からではなく、**このデータ規模・学習設定で安定的に扱える理論矯正の強さには天井があり、その天井がλ=0.5付近にある**ことをアンサンブルという追加の手段でも確認した。以降の分析は、この結論を踏まえてλ=0.5・アンサンブル版（`data/processed/stage3_ensemble.pkl`）を正式な基準として使う。
