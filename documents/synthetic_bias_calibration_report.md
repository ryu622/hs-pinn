# 課題B：合成データによる構造的バイアスのキャリブレーション

計画書10.11節・10.10節項目14に対応。「超過逸脱度＝d(観測,modelB)-d(観測,modelA)は、modelBが理論への矯正で単一の理想形に強く引き寄せられる分、真の戦術逸脱がゼロでも構造的にmodelAより観測から離れやすいのではないか」という懸念（`documents/hs_deviation_issues.md`課題B）を、合成データで定量的に検証した。

コード：`scripts/synthetic_bias_calibration.py`

## 方法

1. 全502件でmodelB（λ=0.5）を1回学習し、その予測をY_theory（理論的に理想的な守備）とする
2. Y_theoryに現実的なノイズ（σ）を加えてY_synth（疑似「観測」）を作る。真の戦術逸脱は定義上ゼロ
3. σは、J03WPYの1foldでσ∈{0.5, 1, 1.5, 2}を試し、modelA_synthのdist_A（予測しにくさ）が実データのdist_A（約2.43）に最も近くなる値を選定（σ=2.0で選定、gap=0.16）
4. 実データと全く同じ7-fold LOMO CVパイプラインで、Y_synthを新しい「観測」としてmodelA_synth（λ=0）・modelB_synth（λ=0.5）を学習し、超過逸脱度を計算する（真の逸脱がゼロのはずなのに出てくる値＝構造的な下駄）

単一シードでの実施（実データ側の比較対象も単一シード版`stage3_excess_deviation_lam0.5.pkl`を使用し、シード数を揃えた）。

## 結果

| | dist_A | 超過逸脱度 |
|---|---|---|
| 実データ（単一シード、λ=0.5, n=502） | 2.434 | mean=+0.055, std=0.399 |
| 合成データ（真の逸脱ゼロ、σ=2.0で校正、n=502） | 2.563（近い値で校正成功） | **mean=+0.035, std=0.094（構造的な下駄）** |

「予測しにくさ」の水準（dist_A）をほぼ揃えた上で、真の戦術逸脱がゼロのはずの合成データでも超過逸脱度は+0.035と正の値になった。実データの超過逸脱度(+0.055)のうち、**約64%（0.035/0.055）が構造的な下駄で説明できる**。

## 解釈

課題Bの懸念は実際に存在することが確認された。超過逸脱度の**絶対水準**（「平均してこれだけ理論から逸脱している」という記述）は、この構造的な下駄を差し引かずに解釈すべきではない。今後、超過逸脱度の絶対値を報告する際は、この下駄（+0.035程度、σ=2.0での近似値）を差し引いた値（または、この下駄を基準線として明示した上での相対的な大きさ）として扱うべきである。

一方、この下駄はほぼ一定のオフセットとして全イベントに加算される構造であるため、**成功率との回帰係数（β=+0.293、`documents/stage3_ensemble_report.md`）への影響は理論上小さい**——定数オフセットは共分散構造（相関・回帰係数）を変えないため。ただし、下駄の大きさがイベントの特性（守備の広がり具合など）によって系統的に変動する可能性は今回の検証では排除できておらず、その場合は交絡として回帰係数にも影響しうる。この点は今回のキャリブレーションでは検証しきれていない残課題とする。

## 限界

- ノイズはフレーム独立のガウスノイズ（i.i.d.）を仮定しており、実際の人間の動きが持つ時間的な相関（滑らかな軌道）は再現していない。この簡略化がσの校正値・下駄の大きさにどの程度影響するかは未検証
- σの校正は1fold（J03WPY）のみで実施し、7-fold全体では若干のずれ（dist_A_synth=2.563 vs 目標2.434）が生じている
- 単一シードでの実施のため、下駄の推定自体にも学習ノイズが乗っている可能性がある

## 結論

構造的な下駄は無視できない大きさ（実データの超過逸脱度の過半数を占めうる）であることが確認された。超過逸脱度の絶対水準に関する記述は、この結果を踏まえて慎重に行う。一方、これまで報告してきた回帰係数ベースの結果（β=+0.293、疑似反復を考慮すると有意性は未確定）は、この構造的下駄の影響を受けにくいと考えられ、結論を覆すものではない。
