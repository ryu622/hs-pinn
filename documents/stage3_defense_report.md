# 段階3：Leave-One-Match-Out交差検証によるmodelA/B構築と超過逸脱度分析

`resarch_plan.md` 10.4節・10.6節の段階3の実施記録。守備側コンパクトネス（段階1・2を通過）を検証セオリーとして、modelA（データ駆動ghost, λ=0）・modelB（理論駆動ghost, λ>0）を構築し、超過逸脱度と成功率の関係を検証した。

コード：`scripts/stage3_excess_deviation.py`

---

## 手法

- 試合単位のLeave-One-Match-Out交差検証（7試合、各回1試合をholdoutし残り6試合で学習）。502件全件についてmodelA・modelB双方のheld-out予測を取得
- 各fold：30エポック、batch_size=16、`predict_side="defend"`。目標値はそのfoldの学習データ（6試合）から校正（holdout試合の情報が学習・目標値校正に混入しないようにするため）
- 逸脱度 = イベントごとの予測軌道と実軌道の平均距離（守備側全選手・全フレームの平均、m単位）
- 超過逸脱度 = dist(modelB, 実観測) − dist(modelA, 実観測)
- λは段階2（`documents/stage2_defense_report.md`）で基準(a)(b)(c)を通過した候補から選定

## 結果：λ=2.0（当初の想定値）

| | 値 |
|---|---|
| 超過逸脱度 平均±std | 0.219 ± 0.601 |
| 生の相関（交絡無視） | r=+0.024, p=0.592 |
| 交絡制御後（奪取位置で制御） | β=+0.286, p=0.072（有意水準未達） |

方向は理論と整合的（超過逸脱度が大きいほど成功しやすい）だが、統計的に確信を持てる水準には届かなかった。超過逸脱度は2つのモデルの予測ノイズの差分であるため本質的にノイズが多く、λ=2.0のマイルドな矯正（段階2でL_compactを7%程度動かす水準）では、modelBがmodelAと十分に区別のつく基準線になりきれていない可能性が考えられた。

## 結果：λ=8.0（段階2で基準通過済みのより強い矯正）

| | 値 |
|---|---|
| 超過逸脱度 平均±std | 0.797 ± 0.774 |
| 生の相関（交絡無視） | r=+0.067, p=0.131 |
| 交絡制御後（奪取位置で制御） | **β=+0.389, p=0.0108** |

λ=8.0では交絡制御後に明確に有意（p=0.0108）。信号対雑音比（平均/std）も0.36→1.03に改善しており、より強い理論的矯正がノイズに対して信号を際立たせた形。生の相関は依然弱い（p=0.131）が、段階1の守備側コンパクトネス（`documents/stage1_defense_report.md`）と同様、奪取位置を制御することで信号が明確になるという同じパターンが再現された。

## 結論

超過逸脱度（modelBの理論的矯正がどれだけ実観測から追加で乖離するか）は、**λが十分強い場合に**、奪取位置を制御した上で攻撃側の成功率と有意に関係する（β=+0.389, p=0.0108, n=502）。方向は「守備がmodelBの理論的理想像から余分に逸脱しているほど、カウンターが成功しやすい」というもので、段階1の直接相関・元々の理論仮説（間延びした守備＝カウンターが刺さりやすい）と一貫している。

以降の分析（超過逸脱度の選手・チーム別集計、定性的ケーススタディ）はλ=8.0の結果を使う。λ=2.0の結果は「弱い矯正では信号が埋もれる」という参考記録として残す。
